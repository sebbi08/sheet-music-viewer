# Zoomen im Bearbeiten-Modus – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Im Stift-Modus mit zwei Fingern, Strg + Rad oder Trackpad-Pinch bis 20× zoomen und verschieben, mit scharfer Seite und scharfen Markierungen, ohne dass sich das Speichern ändert.

**Architecture:** Eine reine Rechenschicht (`src/markup/editZoom.ts`) beschreibt den Ausschnitt als `{ zoom, x, y }` und liefert daraus die Ansichts-Transformation von fabric. Ein reiner Gesten-Zustandsautomat (`src/markup/editGestures.ts`) entscheidet aus Zeigerereignissen, wann eine Geste beginnt, welcher Strich verworfen wird und welcher Ausschnitt gilt. Ein Renderer (`src/markup/zoomPageRenderer.ts`) zeigt unter der Zeichenfläche den sichtbaren Ausschnitt der Seite: erst vergrößert, nach 200 ms scharf von pdf.js. `SheetViewer.vue` bindet die drei beim Öffnen und Schließen des Stift-Modus an.

**Tech Stack:** TypeScript, Vue 3 + Vuetify, fabric 7.4, pdf.js 6.5, Electron 45, vitest, Playwright `_electron` (headless, Touch über das DevTools-Protokoll).

**Spec:** `docs/superpowers/specs/2026-11-23-edit-zoom-design.md`

## Global Constraints

- Zoom von `1` (ganze Seite) bis `20`; kleiner als 1 nie; der Ausschnitt nie über die Seitenränder hinaus.
- Zwei **Touch**-Zeiger = Geste. Stift beginnt nie eine Geste, ein Stiftstrich wird nie verworfen; solange der Stift aufliegt, werden Touch-Zeiger ignoriert. Maus zählt nie als Finger.
- Strich bzw. Ziehen des ersten Fingers: verwerfen, wenn er beim Landen des zweiten Fingers jünger als `300` ms ist; sonst an der Stelle beenden und behalten.
- Scharfes Nachzeichnen etwa `200` ms nach dem Ende einer Geste bzw. Radbewegung; laufendes Rendern wird bei neuer Geste abgebrochen; gleiche Render-Einstellungen wie die normale Seite (eigene Markierungsstempel ausgeblendet).
- Objekte behalten ihre Koordinaten (Zoom nur über `viewportTransform`); `payloadFromCanvas`, das Speichern und der Änderungsvergleich (`editSnapshot`) bleiben unverändert. Nur zoomen und verlassen speichert nichts.
- Strichstärke gilt für die Seite (Brush-Breite in Szenen-Einheiten, wie fabric es unter der Transformation tut).
- Markierungen bei jeder Stufe scharf: Objekt-Zwischenspeicher auf der Zeichenfläche des Stift-Modus verhindern; die globale fabric-Konfiguration nicht ändern (`src/markup/renderPng.ts` nutzt sie).
- Strg + Rad nur im Stift-Modus abfangen (`preventDefault`); `src/main.ts` und die normale Ansicht bleiben unberührt.
- Zoom zurück auf 1 beim Verlassen des Stift-Modus und bei einem Neuzeichnen wegen Größenänderung (`onResize`).
- Neue Symbole und Texte in der Mitte des sichtbaren Ausschnitts.
- Normale Ansicht, Halbseiten, Teiler und deren Canvases unverändert. `SheetViewer.vue`: nur anbinden, kein Umbau.
- GUI-Tests nur headless; `Noten/` nie öffnen. Conventional Commits, Body-Zeilen ≤ 100 Zeichen. Prüfbefehle `npm test`, `npm run lint`, `npx vitest run -c vitest.visual.config.mts <datei>`.

## Review Focus

1. **Gezoomt zeichnen, dann mit dem Zurück-Pfeil das Blatt verlassen:** der Strich wird gespeichert und liegt auf der Seite dort, wo er ungezoomt läge. → Task 3, e2e „a stroke drawn zoomed is saved where it would be unzoomed, also when leaving with the back arrow“.
2. **Hand liegt beim Stiftschreiben auf:** Stift zeichnet, ein Finger (oder zwei) berühren → kein Zoom, kein verlorener Strich. → Task 2, Tests „touches while the pen is down never start a gesture“ und „a pen stroke is never discarded“.
3. **Pinch beginnt auf einem Symbol im Hand-Modus:** das Symbol springt zurück, statt mitzuwandern. → Task 4, e2e „a pinch that starts on a symbol in hand mode leaves the symbol where it was“.
4. **Schnell hintereinander zoomen:** ein älteres, langsameres Rendern darf das Bild der neueren Stufe nicht überschreiben. → Task 3, e2e „rapid wheel zooming ends with a sharp picture of the last view“.
5. **Fenster ändert gezoomt seine Größe:** zurück auf 1×, kein verirrtes Ausschnitt-Bild bleibt stehen. → Task 3, e2e „a resize while zoomed returns to the whole page“.

  export const MIN_ZOOM = 1;
  export const MAX_ZOOM = 20;
  /** Screen position of a canvas point p: p * zoom + (x, y), in CSS px of the edit canvas; x, y <= 0. */
  export interface ZoomView { zoom: number; x: number; y: number }
  export interface Size { width: number; height: number }   // CSS size of the edit canvas
  export interface Point { x: number; y: number }
  export const FIT_VIEW: ZoomView;                           // { zoom: 1, x: 0, y: 0 }
  export function clampView(view: ZoomView, size: Size): ZoomView;
  /** Multiplies the zoom by `factor`, keeping the screen point `at` over the same canvas point (unless clamped). */
  export function zoomAt(view: ZoomView, factor: number, at: Point, size: Size): ZoomView;
  export function panBy(view: ZoomView, dx: number, dy: number, size: Size): ZoomView;
  /** View for two fingers that moved from (a0, b0) to (a1, b1), starting from `start`: zoom by the distance
   *  ratio, and the canvas point under the start midpoint follows the current midpoint. */
  export function pinchView(start: ZoomView, a0: Point, b0: Point, a1: Point, b1: Point, size: Size): ZoomView;
  /** Zoom factor of one wheel event with Ctrl: Math.exp(-clamp(deltaY, -200, 200) * 0.0025). */
  export function wheelZoomFactor(deltaY: number): number;
  export function toViewportTransform(view: ZoomView): [number, number, number, number, number, number]; // [zoom,0,0,zoom,x,y]
  /** Canvas point shown at the centre of the screen area. */
  export function viewCenter(view: ZoomView, size: Size): Point;
  export const isZoomed: (view: ZoomView) => boolean;        // zoom > 1
  ```

- [ ] **Step 1: Write the failing tests** (`size = { width: 600, height: 800 }`):
  - `clampView`: zoom 0.5 → 1 with x = y = 0; zoom 30 → 20; at zoom 2, x = 10 → 0 and x = -900 → -600 (= width − width·zoom); same for y with height.
  - `zoomAt(FIT_VIEW, 2, { x: 300, y: 400 })` → `{ zoom: 2, x: -300, y: -400 }`; the canvas point under a screen point away from the edges (e.g. (250, 300) at zoom 2 → 4) stays under it (screen = p·zoom + offset, ±1e-9); zooming out below 1 returns `FIT_VIEW`; at an edge the result is clamped (zoomAt(FIT_VIEW, 2, {x: 0, y: 0}) → x = y = 0).
  - `panBy` moves by (dx, dy) and clamps; at zoom 1 it always returns `FIT_VIEW`.
  - `pinchView`: fingers spreading from distance 100 to 200 around a fixed midpoint (300, 400) from `FIT_VIEW` → zoom 2, midpoint canvas point fixed; fingers moving together by (+50, 0) at zoom 2 → x changes by +50 (clamped where needed); distance ratio pushing zoom past 20 → 20.
  - `wheelZoomFactor(-100)` > 1, `wheelZoomFactor(100)` = 1 / `wheelZoomFactor(-100)` (±1e-12), `wheelZoomFactor(1000)` = `wheelZoomFactor(200)`.
  - `toViewportTransform({ zoom: 3, x: -5, y: -7 })` → `[3, 0, 0, 3, -5, -7]`; `viewCenter({ zoom: 2, x: -300, y: -400 }, size)` → `{ x: 300, y: 400 }`.

  export const DISCARD_WINDOW_MS = 300;
  export type PointerKind = "touch" | "pen" | "mouse";
  export type GestureAction =
    | { kind: "pass" }                         // the event belongs to fabric as today
    | { kind: "block" }                        // keep the event away from fabric, nothing else happens
    | { kind: "start"; discardFirst: boolean } // a two-finger gesture begins; end the first finger's fabric
                                               // input and, if discardFirst, undo it (stroke / object drag)
    | { kind: "view"; view: ZoomView }         // apply this view
    | { kind: "end" };                         // the gesture is over
  export interface GestureTracker {
    down(id: number, kind: PointerKind, at: Point, timeMs: number): GestureAction;
    move(id: number, at: Point, timeMs: number): GestureAction;
    up(id: number, timeMs: number): GestureAction;   // also for cancel
    /** true while a gesture runs or a finger of an ended gesture is still down. */
    blocking(): boolean;
  }
  export function createGestureTracker(currentView: () => ZoomView, size: () => Size): GestureTracker;
  ```

- [ ] **Step 1: Write the failing tests**:
  - one touch `down` → `pass`, its `move`s → `pass`, `up` → `pass` (a single finger draws as today).
  - `"two touches start a gesture and discard a young first stroke"`: touch 1 down at t = 0, touch 2 down at t = 299 → `{ kind: "start", discardFirst: true }`; at t = 300 → `discardFirst: false`.
  - during the gesture, `move` of either finger → `{ kind: "view" }` equal to `pinchView(startView, …)` for the current positions; a third touch `down` → `block`, its moves → `block`.
  - lifting one of the two fingers → `end`; the remaining finger's `move`/`up` → `block`; after it lifts, a new single touch → `pass` and `blocking()` is false.
  - `"touches while the pen is down never start a gesture"`: pen down → `pass`; two touch downs → `block` each, their moves → `block`; pen up → `pass`; afterwards a fresh pair of touches starts a gesture.
  - `"a pen stroke is never discarded"`: touch 1 down (t = 0), pen down (t = 100) → `pass`; touch 2 down (t = 150) → `block` (no `start`).
  - a mouse `down` never counts as a finger: mouse down + one touch down → the touch gets `pass`.
  - the `view` actions start from `currentView()` at the moment of `start`.
